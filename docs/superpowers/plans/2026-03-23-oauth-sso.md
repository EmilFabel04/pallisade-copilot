# OAuth SSO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate from NextAuth v4 to Auth.js v5 and add Google, GitHub, Microsoft, and per-org OIDC authentication with invite-only onboarding, account linking, and enforced SSO.

**Architecture:** Auth.js v5 config at project root exports `auth()`, `handlers`, `signIn`, `signOut`. Middleware protects dashboard routes at the edge. The `signIn` callback handles invite redemption and SSO enforcement. Per-org OIDC uses dynamic provider loading via signed cookie + state parameter.

**Tech Stack:** Auth.js v5 (next-auth@5), @auth/prisma-adapter, Prisma, PostgreSQL, bcryptjs, AES-256-GCM encryption

**Spec:** `docs/superpowers/specs/2026-03-23-oauth-sso-design.md`

```typescript
import NextAuth from 'next-auth';
import { PrismaAdapter } from '@auth/prisma-adapter';
import Credentials from 'next-auth/providers/credentials';
import Google from 'next-auth/providers/google';
import GitHub from 'next-auth/providers/github';
import MicrosoftEntraID from 'next-auth/providers/microsoft-entra-id';
import bcrypt from 'bcryptjs';
import prisma from '@/lib/db';

export const { auth, handlers, signIn, signOut } = NextAuth({
  adapter: PrismaAdapter(prisma),
  session: { strategy: 'jwt' },
  pages: {
    signIn: '/login',
    error: '/login',
  },
  providers: [
    Credentials({
      name: 'credentials',
      credentials: {
        email: { label: 'Email', type: 'email' },
        password: { label: 'Password', type: 'password' },
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) {
          throw new Error('Email and password are required');
        }

        const user = await prisma.user.findUnique({
          where: { email: credentials.email as string },
          include: { organization: true },
        });

        if (!user || !user.passwordHash) {
          throw new Error('Invalid email or password');
        }

        const isValid = await bcrypt.compare(
          credentials.password as string,
          user.passwordHash
        );
        if (!isValid) {
          throw new Error('Invalid email or password');
        }

        return {
          id: user.id,
          email: user.email,
          name: user.name,
          image: user.image,
          organizationId: user.organizationId,
          timezone: user.timezone,
        };
      },
    }),

    // Google OAuth (optional)
    ...(process.env.GOOGLE_CLIENT_ID && process.env.GOOGLE_CLIENT_SECRET
      ? [Google({
          clientId: process.env.GOOGLE_CLIENT_ID,
          clientSecret: process.env.GOOGLE_CLIENT_SECRET,
        })]
      : []),

    // GitHub OAuth (optional)
    ...(process.env.GITHUB_CLIENT_ID && process.env.GITHUB_CLIENT_SECRET
      ? [GitHub({
          clientId: process.env.GITHUB_CLIENT_ID,
          clientSecret: process.env.GITHUB_CLIENT_SECRET,
        })]
      : []),

    // Microsoft Entra ID (optional)
    ...(process.env.MICROSOFT_CLIENT_ID && process.env.MICROSOFT_CLIENT_SECRET
      ? [MicrosoftEntraID({
          clientId: process.env.MICROSOFT_CLIENT_ID,
          clientSecret: process.env.MICROSOFT_CLIENT_SECRET,
          tenantId: process.env.MICROSOFT_TENANT_ID || 'common',
        })]
      : []),
  ],
  callbacks: {
    async signIn({ user, account, profile }) {
      // Credentials provider — handled by authorize(), always allow
      if (account?.provider === 'credentials') {
        return true;
      }

      // OAuth provider — check if user already exists with an org
      const email = user.email;
      if (!email) return false;

      const existingUser = await prisma.user.findUnique({
        where: { email },
        include: { organization: true },
      });

      if (existingUser?.organizationId) {
        // Existing user with org — check SSO enforcement for credentials
        // (OAuth is always allowed even under SSO_ONLY)
        return true;
      }

      // New user or existing user without org — check for invite
      const invite = await prisma.teamInvite.findFirst({
        where: {
          email,
          status: 'PENDING',
          expiresAt: { gt: new Date() },
        },
        include: { organization: true },
      });

      if (!invite) {
        return '/login?error=NoInvite';
      }

      // Verify email is verified by the OAuth provider
      // GitHub doesn't guarantee email_verified — require explicit true
      const emailVerified = (profile as any)?.email_verified;
      if (emailVerified !== true && account?.provider !== 'credentials') {
        return '/login?error=UnverifiedEmail';
      }

      // Redeem invite in a transaction
      const userId = existingUser?.id || user.id;
      await prisma.$transaction([
        prisma.teamMember.create({
          data: {
            userId,
            organizationId: invite.organizationId,
            role: invite.role,
            status: 'ACTIVE',
            joinedAt: new Date(),
          },
        }),
        prisma.user.update({
          where: { id: userId },
          data: { organizationId: invite.organizationId },
        }),
        prisma.teamInvite.update({
          where: { id: invite.id },
          data: { status: 'ACCEPTED', respondedAt: new Date() },
        }),
      ]);

      return true;
    },

    async jwt({ token, user, trigger }) {
      if (user) {
        token.id = user.id;
        token.organizationId = (user as any).organizationId;
        token.timezone = (user as any).timezone;
      }

      // On first OAuth sign-in, user object may not have organizationId yet
      // (it was set in signIn callback after user was created)
      // Re-fetch from DB on sign-in trigger
      if (trigger === 'signIn' && token.id) {
        const dbUser = await prisma.user.findUnique({
          where: { id: token.id as string },
          select: { organizationId: true, timezone: true },
        });
        if (dbUser) {
          token.organizationId = dbUser.organizationId;
          token.timezone = dbUser.timezone;
        }
      }

      // Re-fetch from DB when client calls useSession().update()
      if (trigger === 'update' && token.id) {
        const dbUser = await prisma.user.findUnique({
          where: { id: token.id as string },
          select: { timezone: true, organizationId: true },
        });
        if (dbUser) {
          token.timezone = dbUser.timezone;
          token.organizationId = dbUser.organizationId;
        }
      }

      return token;
    },

    async session({ session, token }) {
      if (session.user) {
        (session.user as any).id = token.id;
        (session.user as any).organizationId = token.organizationId;
        (session.user as any).timezone = token.timezone;
      }
      return session;
    },
  },
});
```

import { auth } from '@/auth';
import { NextResponse } from 'next/server';

export default auth((req) => {
  const isLoggedIn = !!req.auth;
  const isAuthPage = req.nextUrl.pathname.startsWith('/login') ||
                     req.nextUrl.pathname.startsWith('/signup');
  const isDashboard = req.nextUrl.pathname.startsWith('/dashboard');
  const isOnboarding = req.nextUrl.pathname.startsWith('/onboarding');

  // Skip middleware if feature flag is off
  if (process.env.ENABLE_AUTH_MIDDLEWARE !== 'true') {
    return NextResponse.next();
  }

  // Redirect logged-in users away from auth pages
  if (isLoggedIn && isAuthPage) {
    return NextResponse.redirect(new URL('/dashboard', req.nextUrl));
  }

  // Protect dashboard and onboarding routes
  if (!isLoggedIn && (isDashboard || isOnboarding)) {
    return NextResponse.redirect(new URL('/login', req.nextUrl));
  }

  return NextResponse.next();
});

export const config = {
  matcher: ['/dashboard/:path*', '/onboarding/:path*', '/login', '/signup'],
};
```

const rateMap = new Map<string, { count: number; resetAt: number }>();

export function rateLimit(key: string, limit: number, windowMs: number): boolean {
  const now = Date.now();
  const entry = rateMap.get(key);

  if (!entry || now > entry.resetAt) {
    rateMap.set(key, { count: 1, resetAt: now + windowMs });
    return true;
  }

  if (entry.count >= limit) {
    return false;
  }

  entry.count++;
  return true;
}
```

import { NextRequest, NextResponse } from 'next/server';
import prisma from '@/lib/db';
import { rateLimit } from '@/lib/rate-limit';

export async function POST(request: NextRequest) {
  // Rate limit by IP
  const ip = request.headers.get('x-forwarded-for') || 'unknown';
  if (!rateLimit(ip, 10, 60_000)) {
    return NextResponse.json(
      { error: 'Too many requests' },
      { status: 429 }
    );
  }

  try {
    const { email } = await request.json();
    if (!email || typeof email !== 'string' || !email.includes('@')) {
      return NextResponse.json({ hasOidc: false });
    }

    const domain = email.split('@')[1].toLowerCase();

    const org = await prisma.organization.findFirst({
      where: { domain },
      include: {
        oidcConfig: {
          select: { enabled: true, displayName: true },
        },
      },
    });

    if (!org?.oidcConfig?.enabled) {
      // Always return same shape — don't reveal org existence
      return NextResponse.json({ hasOidc: false });
    }

    return NextResponse.json({
      hasOidc: true,
      displayName: org.oidcConfig.displayName,
    });
  } catch {
    return NextResponse.json({ hasOidc: false });
  }
}

export async function DELETE(request: NextRequest) {
  const session = await auth();
  if (!session?.user?.id) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  const userId = (session.user as any).id;
  const { accountId } = await request.json();

  // Safety check — cannot remove last auth method
  const accountCount = await prisma.account.count({ where: { userId } });
  const user = await prisma.user.findUnique({
    where: { id: userId },
    select: { passwordHash: true },
  });

  const totalMethods = accountCount + (user?.passwordHash ? 1 : 0);

  if (totalMethods <= 1) {
    return NextResponse.json(
      { error: 'Cannot remove your only authentication method. Set a password or connect another provider first.' },
      { status: 400 }
    );
  }

  // Verify the account belongs to the user
  const account = await prisma.account.findFirst({
    where: { id: accountId, userId },
  });

  if (!account) {
    return NextResponse.json({ error: 'Account not found' }, { status: 404 });
  }

  await prisma.account.delete({ where: { id: accountId } });

  return NextResponse.json({ success: true });
}

## Task 15: OIDC Cookie Helpers

**Files:**
- Create: `lib/auth-cookies.ts`

- [ ] **Step 1: Create auth-cookies.ts**

```typescript
import { cookies } from 'next/headers';
import crypto from 'crypto';

const COOKIE_NAME = 'oidc_org_id';
const COOKIE_MAX_AGE = 300; // 5 minutes

function getSigningKey(): string {
  const secret = process.env.AUTH_SECRET || process.env.NEXTAUTH_SECRET;
  if (!secret) throw new Error('AUTH_SECRET or NEXTAUTH_SECRET must be set');
  return secret;
}

function sign(value: string): string {
  const key = getSigningKey();
  const hmac = crypto.createHmac('sha256', key);
  hmac.update(value);
  return `${value}.${hmac.digest('hex')}`;
}

function verify(signedValue: string): string | null {
  const lastDot = signedValue.lastIndexOf('.');
  if (lastDot === -1) return null;

  const value = signedValue.substring(0, lastDot);
  const signature = signedValue.substring(lastDot + 1);

  const key = getSigningKey();
  const hmac = crypto.createHmac('sha256', key);
  hmac.update(value);
  const expected = hmac.digest('hex');

  if (!crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected))) {
    return null;
  }

  return value;
}

export async function setOidcOrgCookie(orgId: string): Promise<void> {
  const cookieStore = await cookies();
  cookieStore.set(COOKIE_NAME, sign(orgId), {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: COOKIE_MAX_AGE,
    path: '/',
  });
}

export async function getOidcOrgId(): Promise<string | null> {
  const cookieStore = await cookies();
  const cookie = cookieStore.get(COOKIE_NAME);
  if (!cookie?.value) return null;
  return verify(cookie.value);
}

export async function clearOidcOrgCookie(): Promise<void> {
  const cookieStore = await cookies();
  cookieStore.delete(COOKIE_NAME);
}
```

This is the most complex part. Auth.js v5's static provider list won't work for per-org OIDC because it fetches the discovery document at startup. Instead, build a **custom OAuth handler** outside of Auth.js that manually implements the OIDC authorization code flow.

Create two new route files:

**`app/api/auth/oidc/authorize/route.ts`** — Initiates the OIDC flow:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import prisma from '@/lib/db';
import { decrypt } from '@/lib/crypto';
import { getOidcOrgId } from '@/lib/auth-cookies';
import crypto from 'crypto';

export async function GET(request: NextRequest) {
  const orgId = await getOidcOrgId();
  if (!orgId) {
    return NextResponse.redirect(new URL('/login?error=NoOidcConfig', request.url));
  }

  const config = await prisma.orgOidcConfig.findUnique({
    where: { organizationId: orgId },
  });

  if (!config?.enabled) {
    return NextResponse.redirect(new URL('/login?error=NoOidcConfig', request.url));
  }

  // Fetch OIDC discovery
  const discoveryUrl = `${config.issuerUrl.replace(/\/$/, '')}/.well-known/openid-configuration`;
  const discovery = await fetch(discoveryUrl).then(r => r.json());

  // Generate state and nonce
  const state = crypto.randomBytes(32).toString('hex');
  const nonce = crypto.randomBytes(16).toString('hex');

  // Store state in a cookie for CSRF verification (include orgId for callback)
  const stateData = JSON.stringify({ state, orgId, nonce });
  const response = NextResponse.redirect(
    `${discovery.authorization_endpoint}?` +
    new URLSearchParams({
      client_id: config.clientId,
      redirect_uri: `${process.env.NEXTAUTH_URL}/api/auth/oidc/callback`,
      response_type: 'code',
      scope: config.scopes,
      state,
      nonce,
    }).toString()
  );

  response.cookies.set('oidc_state', stateData, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 300,
    path: '/',
  });

  return response;
}
```

**`app/api/auth/oidc/callback/route.ts`** — Handles the OIDC callback:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import prisma from '@/lib/db';
import { decrypt } from '@/lib/crypto';

export async function GET(request: NextRequest) {
  const code = request.nextUrl.searchParams.get('code');
  const state = request.nextUrl.searchParams.get('state');
  const stateCookie = request.cookies.get('oidc_state')?.value;

  if (!code || !state || !stateCookie) {
    return NextResponse.redirect(new URL('/login?error=OidcFailed', request.url));
  }

  // Verify state
  const stateData = JSON.parse(stateCookie);
  if (stateData.state !== state) {
    return NextResponse.redirect(new URL('/login?error=OidcFailed', request.url));
  }

  const { orgId } = stateData;

  // Load OIDC config
  const config = await prisma.orgOidcConfig.findUnique({
    where: { organizationId: orgId },
  });
  if (!config) {
    return NextResponse.redirect(new URL('/login?error=OidcFailed', request.url));
  }

  // Fetch discovery for token endpoint
  const discoveryUrl = `${config.issuerUrl.replace(/\/$/, '')}/.well-known/openid-configuration`;
  const discovery = await fetch(discoveryUrl).then(r => r.json());

  // Exchange code for tokens
  const tokenRes = await fetch(discovery.token_endpoint, {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      grant_type: 'authorization_code',
      code,
      redirect_uri: `${process.env.NEXTAUTH_URL}/api/auth/oidc/callback`,
      client_id: config.clientId,
      client_secret: decrypt(config.clientSecret),
    }),
  });

  const tokens = await tokenRes.json();
  if (!tokens.access_token) {
    return NextResponse.redirect(new URL('/login?error=OidcFailed', request.url));
  }

  // Fetch user info
  const userInfo = await fetch(discovery.userinfo_endpoint, {
    headers: { Authorization: `Bearer ${tokens.access_token}` },
  }).then(r => r.json());

  const email = userInfo.email;
  if (!email) {
    return NextResponse.redirect(new URL('/login?error=OidcFailed', request.url));
  }

  // Find or create user, check invite (same logic as signIn callback)
  let user = await prisma.user.findUnique({
    where: { email },
    include: { organization: true },
  });

  if (!user) {
    // Check for invite
    const invite = await prisma.teamInvite.findFirst({
      where: { email, status: 'PENDING', expiresAt: { gt: new Date() } },
    });

    if (!invite) {
      return NextResponse.redirect(new URL('/login?error=NoInvite', request.url));
    }

    // Create user and redeem invite in transaction
    user = await prisma.$transaction(async (tx) => {
      const newUser = await tx.user.create({
        data: {
          email,
          name: userInfo.name || userInfo.preferred_username || email,
          emailVerified: new Date(),
          organizationId: invite.organizationId,
        },
        include: { organization: true },
      });

      await tx.teamMember.create({
        data: {
          userId: newUser.id,
          organizationId: invite.organizationId,
          role: invite.role,
          status: 'ACTIVE',
          joinedAt: new Date(),
        },
      });

      await tx.teamInvite.update({
        where: { id: invite.id },
        data: { status: 'ACCEPTED', respondedAt: new Date() },
      });

      await tx.account.create({
        data: {
          userId: newUser.id,
          type: 'oidc',
          provider: `oidc-${orgId}`,
          providerAccountId: userInfo.sub,
          access_token: tokens.access_token,
          refresh_token: tokens.refresh_token,
          expires_at: tokens.expires_in
            ? Math.floor(Date.now() / 1000) + tokens.expires_in
            : undefined,
          id_token: tokens.id_token,
        },
      });

      return newUser;
    });
  } else if (!user.organizationId) {
    // Existing user without org — check for invite
    const invite = await prisma.teamInvite.findFirst({
      where: { email, status: 'PENDING', expiresAt: { gt: new Date() } },
    });
    if (!invite) {
      return NextResponse.redirect(new URL('/login?error=NoInvite', request.url));
    }
    // Redeem invite
    await prisma.$transaction([
      prisma.teamMember.create({
        data: {
          userId: user.id,
          organizationId: invite.organizationId,
          role: invite.role,
          status: 'ACTIVE',
          joinedAt: new Date(),
        },
      }),
      prisma.user.update({
        where: { id: user.id },
        data: { organizationId: invite.organizationId },
      }),
      prisma.teamInvite.update({
        where: { id: invite.id },
        data: { status: 'ACCEPTED', respondedAt: new Date() },
      }),
    ]);
  }

  // Create a session by calling NextAuth's signIn with credentials
  // Use a special internal token that the credentials provider can verify
  // This bridges the OIDC flow into NextAuth's session management
  const { signIn } = await import('@/auth');
  // Note: Server-side signIn from Auth.js v5 can create a session directly
  // The exact API may vary — consult Auth.js docs for server-side session creation
  // Fallback: redirect to a special callback URL that sets the session cookie

  const response = NextResponse.redirect(new URL('/dashboard', request.url));
  response.cookies.delete('oidc_state');
  return response;
}
```

**Important:** The callback's final step (creating a NextAuth session for the OIDC user) requires bridging into Auth.js's session system. Options:

2. Create a JWT manually using the same secret and set it as a cookie
3. Redirect to a special internal endpoint that triggers `signIn('credentials')` with a one-time token

The exact approach depends on Auth.js v5's server-side session creation API. Research this during implementation and choose the simplest working approach.
